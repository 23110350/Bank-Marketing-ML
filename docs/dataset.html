📋 Dataset Overview

Where the data comes from and what it represents

The dataset is sourced from the UCI Machine Learning Repository and relates to direct marketing campaigns (phone calls) of a Portuguese banking institution.

The goal is to predict whether a client will subscribe to a term deposit (binary target: yes / no). The dataset reflects a real business challenge — a heavily imbalanced target where most customers say NO.

This dataset is widely used in ML research and competitions. It was collected between May 2008 and November 2010.

⚖️ Class Imbalance

Understanding the minority subscriber class

Class 0 — No

39,922 observations (88.3%)

Class 1 — Yes

5,289 observations (11.7%)

Modeling implication: A majority-class classifier can achieve high accuracy while failing to identify subscribers. The updated experiment uses class weighting where supported and reports precision, recall, F1-score, balanced accuracy, and ROC-AUC. It does not use SMOTE.

✂️ Train / Test Split

How the data was divided for the updated experiment

Evaluation design: A stratified 80:20 split produced 36,168 training observations and 9,043 held-out test observations. Stratified 3-fold cross-validation was performed on the training set only. Preprocessing was fitted within each training fold; the held-out test set was not resampled or used for model selection.
