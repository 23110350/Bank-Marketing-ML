📌 What is a Decision Tree?

Understanding the algorithm

A Decision Tree is a flowchart-like model that splits data into branches based on feature values. Each internal node represents a decision rule, each branch represents an outcome, and each leaf node represents a class label.

The tree is built by selecting the feature that provides the best split at each node using criteria such as Gini Impurity or Information Gain (Entropy).

Decision Trees are highly interpretable — you can literally follow the path from root to leaf to understand why a prediction was made. However, they can easily overfit without proper pruning.

Gini Impurity: Gini = 1 − Σ(pᵢ)²

✅ Advantages

  • Highly interpretable
  • No feature scaling needed
  • Handles non-linear patterns
  • Works with mixed data types

❌ Limitations

  • Prone to overfitting
  • Unstable — small data changes alter tree
  • Biased toward features with more levels

Interpretation

The single Decision Tree has the lowest ROC-AUC and subscriber F1 among the four candidate models. Its lower precision means that a substantial number of customers predicted to subscribe do not subscribe.

All metrics above use the positive class (subscription) for precision, recall and F1. The held-out test set contains 9,043 observations, including 1,058 subscribers and 7,985 non-subscribers.

How this model was evaluated

Consistent experimental design across all four classifiers

  • Input features exclude duration, which is only available after the call.
  • Data are split using a stratified 80:20 train/test split (random state 42).
  • Three-fold stratified cross-validation is performed on the training partition only.
  • Imputation and one-hot encoding are fitted inside scikit-learn pipelines within each fold.
  • Class weighting is applied to Logistic Regression, Decision Tree and Random Forest as configured in the experiment script; no synthetic oversampling is used.
  • Reported test metrics use the default 0.50 probability threshold. The test set is not used for model selection.
