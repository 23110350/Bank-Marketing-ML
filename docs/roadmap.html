📌 Project Overview

What is this project about?

This project applies Machine Learning to a real-world banking problem. Using data from a Portuguese bank's telemarketing campaigns, we compared 4 base classifiers and a separately tuned Random Forest variant to predict whether a customer will subscribe to a term deposit.

The dataset contains 45,211 records and 17 features including customer demographics, financial info, and campaign history — sourced from the UCI Machine Learning Repository .

Reproducing the Analysis

Steps to regenerate the model comparison

  1. Download or clone the source repository and ensure data/bank-full.csv is present.
  2. Install Python 3.10+ and the packages listed in requirements.txt.
  3. From the repository root, run python analysis/reproduce_analysis.py.
  4. Inspect outputs/model_comparison.csv for final held-out metrics, outputs/test_predictions.json for held-out predictions, and outputs/validation_oof_predictions.json for the training OOF predictions used by the threshold explorer.
  5. For local preview, run python -m http.server 8000 --directory website from the repository root and open http://localhost:8000.
  6. For GitHub Pages, publish the repository's docs/ folder from the main branch in Pages settings. After website edits, run python scripts/sync_website.py to refresh docs/.

The threshold explorer uses precomputed out-of-fold predictions from the training partition (validation_oof_predictions.json). Held-out test predictions (test_predictions.json) are kept separate for final evaluation and are not loaded by the explorer. The browser recalculates threshold-dependent metrics; it does not retrain models.
