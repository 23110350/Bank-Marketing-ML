⚙️ Data Preparation

Data Preprocessing

The final experiment's leakage-aware data preparation workflow

Preprocessing decisions

All 45,211 observations are retained and transformations are learned from training data only.

Prediction-time leakage

The duration variable is excluded because call duration is only known after the marketing call. The intended prediction is made before the call, so duration would not be available at decision time.

Preserving observations

Zero-duration observations are not removed. This keeps the full dataset and avoids changing the population based on a post-call variable.

Previous-contact information

The original pdays = -1 value is retained to represent no previous contact. A separate previously_contacted indicator is added to make this distinction explicit.

Class imbalance

No synthetic oversampling is used in the final experiment. Class weighting is applied for Logistic Regression, Decision Tree and Random Forest as configured in the experiment script.

Pipeline transformations

  1. Split the data using a stratified 80:20 train/test split with random state 42.
  2. Impute numeric missing values using the median learned from the relevant training fold.
  3. Impute categorical missing values using the most frequent category learned from the relevant training fold.
  4. One-hot encode categorical variables, ignoring categories not seen during fitting.
  5. Scale numeric features for Logistic Regression; tree-based models use the unscaled numeric pipeline.
  6. Fit preprocessing and the classifier together in a scikit-learn pipeline during cross-validation.

The three-fold cross-validation is performed on the training partition only. The held-out test set is used for the final reported metrics, not model selection.
