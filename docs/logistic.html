📌 What is Logistic Regression?

Understanding the algorithm

Logistic Regression is a statistical model used for binary classification tasks. Despite its name, it is a classification algorithm — not regression.

It uses the sigmoid function to map any input value to a probability between 0 and 1, then applies a threshold (usually 0.5) to classify the output as 0 or 1.

In this project, Logistic Regression serves as our baseline model — a reference point to compare more complex models against.

Sigmoid Function: P(y=1) = 1 / (1 + e-z)

✅ Advantages

  • Fast to train
  • Highly interpretable
  • Works well on linearly separable data
  • Outputs calibrated probabilities

❌ Limitations

  • Assumes linear decision boundary
  • Struggles with complex patterns
  • Sensitive to outliers

Interpretation

Logistic Regression provides a relatively high subscriber recall among the candidate models. It identifies 62.38% of actual subscribers at the default 0.50 threshold, but its precision is 26.67%, so many predicted subscribers do not subscribe.

All metrics above use the positive class (subscription) for precision, recall and F1. The held-out test set contains 9,043 observations, including 1,058 subscribers and 7,985 non-subscribers.

How this model was evaluated

Consistent experimental design across all four classifiers

  • Input features exclude duration, which is only available after the call.
  • Data are split using a stratified 80:20 train/test split (random state 42).
  • Three-fold stratified cross-validation is performed on the training partition only.
  • Imputation and one-hot encoding are fitted inside scikit-learn pipelines within each fold.
  • Class weighting is applied to Logistic Regression, Decision Tree and Random Forest as configured in the experiment script; no synthetic oversampling is used.
  • Reported test metrics use the default 0.50 probability threshold. The test set is not used for model selection.
