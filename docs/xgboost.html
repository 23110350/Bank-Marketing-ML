📌 What is XGBoost?

Understanding the algorithm

XGBoost (Extreme Gradient Boosting) is an optimized distributed gradient boosting library. It builds trees sequentially — each new tree corrects the errors made by the previous one.

Unlike Random Forest which builds trees in parallel, XGBoost builds them one at a time, focusing on the mistakes of the previous iteration. This makes it incredibly powerful for structured/tabular data.

XGBoost dominated ML competitions on Kaggle for years and is widely used in real-world industry applications due to its speed, accuracy, and built-in regularization.

Objective Function: Obj = Σ L(yᵢ, ŷᵢ) + Σ Ω(fₖ)

Where L = loss function  |  Ω = regularization term

✅ Advantages

  • Highest accuracy; recall trade-off
  • Built-in regularization (L1 & L2)
  • Handles missing values natively
  • Fast with parallel computation

❌ Limitations

  • More hyperparameters to tune
  • Less interpretable than LR/DT
  • Slower than simple models

Interpretation

XGBoost achieves the highest accuracy and precision, but identifies only 15.41% of actual subscribers at the default threshold. Its high accuracy should not be interpreted as strong subscriber detection.

All metrics above use the positive class (subscription) for precision, recall and F1. The held-out test set contains 9,043 observations, including 1,058 subscribers and 7,985 non-subscribers.

How this model was evaluated

Consistent experimental design across all four classifiers

  • Input features exclude duration, which is only available after the call.
  • Data are split using a stratified 80:20 train/test split (random state 42).
  • Three-fold stratified cross-validation is performed on the training partition only.
  • Imputation and one-hot encoding are fitted inside scikit-learn pipelines within each fold.
  • Class weighting is applied to Logistic Regression, Decision Tree and Random Forest as configured in the experiment script; no synthetic oversampling is used.
  • Reported test metrics use the default 0.50 probability threshold. The test set is not used for model selection.
