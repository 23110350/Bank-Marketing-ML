Interpretation

What the comparison does—and does not—show

The majority baseline achieves high accuracy because most observations belong to the non-subscriber class, but it has zero recall for subscribers. XGBoost has the highest accuracy in this particular test run, while Random Forest has the highest F1-score among the candidate models. This illustrates why the preferred model depends on the cost of different classification errors.

These results describe one held-out split of this dataset. They do not establish that the models will perform similarly in a different bank, campaign, time period or customer population. Predictive associations should not be interpreted as causal effects.

Additional evaluation checks

Uncertainty, threshold exploration and descriptive error patterns

Threshold sensitivity using out-of-fold predictions

The threshold explorer uses out-of-fold predictions generated on the training partition. Each training observation receives a prediction from a model that did not train on that observation. This makes the threshold exploration separate from the final held-out test evaluation. The explorer is a sensitivity tool; any threshold choice should be justified by the campaign's decision costs and fixed before final test reporting.

Bootstrap uncertainty intervals

The project reports percentile 95% bootstrap intervals for accuracy, precision, recall, F1-score and ROC-AUC on the held-out test set. These intervals describe sampling uncertainty conditional on the chosen split and fitted models; they do not capture variation across different train/test splits or all sources of model-selection uncertainty.

View test-metric bootstrap intervals (CSV)

For the fixed Random Forest model, the bootstrap 95% interval is 0.425–0.469 for F1 and 0.782–0.813 for ROC-AUC. These intervals are conditional on the fixed split and fitted model.

Random Forest error analysis

False-positive and false-negative rates are summarized by job, marital status, education, contact type, previous campaign outcome and age band. These are descriptive group-level diagnostics, not causal explanations. Small groups should be interpreted cautiously.

View Random Forest subgroup error analysis (CSV)

In this split, the Random Forest's false-negative rate varies substantially across groups. For example, the `contact = unknown` group contains 103 actual subscribers, of whom 100 are missed at the 0.50 threshold. This is a descriptive result for this dataset and split; it should be investigated before any operational use and should not be interpreted as a causal effect.

Training-only hyperparameter search

A modest grid search evaluates Random Forest settings using stratified three-fold cross-validation on the training partition, optimizing average precision. The held-out test set is not used to choose hyperparameters. The tuned model is reported separately from the fixed candidate models.
